The solution file `Ecommerce.sln` declares the layered project graph: `Ecommerce.Domain` is the innermost layer with no dependencies; `Ecommerce.Application` depends on Domain; `Ecommerce.Infrastructure` depends on Domain and Application for persistence/external services; `Ecommerce.Api` depends on all three to expose HTTP endpoints. Tests mirror this split into `Domain.Tests`, `Application.Tests`, and `IntegrationTests`. Cross-layer contracts are enforced by the directory layout (`src/` vs `tests/`) and by shared MSBuild properties in `Directory.Build.props` (net8.0, nullable, implicit usings). The `.tools/dotnet-ef.exe` bootstrapper centralizes EF tooling used by Infrastructure migrations, while `scripts/setup.{ps1,sh}` provide cross-platform bootstrap, and `.github/workflows/ci.yml` runs the full build/test pipeline across all projects.
